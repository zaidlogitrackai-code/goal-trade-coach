# وكيل إدارة المخاطر (حارس المخاطر)

## الهدف
وكيل ذكي خاص بالمخاطر يتابعك بنفسه داخل الموقع: يرسل تنبيهات، يذكّرك، ينصحك قبل أي صفقة، بدون أي شيء يدوي. القرار النهائي يبقى لك دائمًا (ينبّه بس، ما يوقف التداول).

## اللي بيصير
1. **مراقبة مستمرة وأنت فاتح الموقع** (كل دقيقة تقريبًا) وتنبيه فوري في الجرس ونافذة تنبيه على الشاشة لما:
   - تقرب من حد الخسارة اليومي (80%) أو توصله: "وقف، لا تتداول اليوم".
   - توصل هدفك اليومي/الأسبوعي/الشهري: "تحقق هدفك، أقفل وارتاح، لا تطمع".
   - تخسر صفقتين ورا بعض: "خذ استراحة".
   - صفقة مفتوحة بدون وقف خسارة: "حط وقف الآن".
   - صفقة مفتوحة صار لها وقت طويل: "راجع الصفقة أو أقفلها".
   - تتجاوز عدد الصفقات المسموح.
   كل تنبيه ينرسل مرة وحدة بس (ما يتكرر عليك).
2. **التنبيهات اللي تطلبها بنفسك:** تقول للمدرب "ذكّرني الساعة 4 أراجع صفقاتي" أو "نبهني كل يوم الصبح بخطتي"، فيحفظها ويرسلها في وقتها.
3. **رسالة الصباح اليومية** تبقى، وتنضاف رسالة مراجعة آخر اليوم (ملخص اليوم + نصيحة لبكرة).
4. **قبل أي صفقة جديدة** (في صفحة الصفقة الجديدة، المدرب، والمحلل): الوكيل يعطيك رأي المخاطر — كم باقي لك من المخاطرة، هل الصفقة تتعدى الحد، ونصيحة واضحة "ادخل / خفّف الحجم / لا تدخل".
5. **الوكلاء يتكلمون مع بعض:** المحلل والمدرب يشوفون تنبيهات المخاطر الأخيرة ويأخذونها بالاعتبار في ردودهم.
6. **صفحة إدارة المخاطر:** قسم "حارس المخاطر" يعرض آخر التنبيهات والتذكيرات اللي طلبتها مع زر حذف، وزر "صحّح لي التعارض" لمشكلة الهدف اليومي 1000 أكبر من حد الربح 500 (الظاهرة في صورتك).

## ملاحظة
التنبيهات تظهر وقت ما الموقع مفتوح (حسب اختيارك). إذا كان مسكّر، تشوف كل اللي فاتك في الجرس أول ما تفتحه.

## تفاصيل تقنية
- جدول `reminders` (user_id, title, body, kind once/daily, at time, next_at, active) + GRANT + RLS مالك فقط.
- عمود `dedupe_key` فريد في `notifications` (user_id, dedupe_key) لمنع التكرار.
- `src/lib/risk-watch.ts` دالة صافية `riskAlerts(settings, trades, now)` ترجع قائمة تنبيهات بمفاتيح يومية — مع اختبارات vitest (80%، الوصول للحد، الهدف، خسارتين متتاليتين، بدون وقف).
- مكوّن `RiskWatcher` في app-shell: كل 60 ثانية يحسب التنبيهات ويحفظ الجديد منها ويعرض toast + Notification API إذا مسموح؛ ويرسل التذكيرات المستحقة.
- إجراءات وكيل جديدة `add_reminder` / `delete_reminder` في agent-actions + AGENT_SCHEMA.
- `eveningReview` server fn كسولة مثل morningGreeting بعد نهاية الجلسة.
- آخر التنبيهات تُضاف لسياق coachReply وanalyzeChart.
- إجراء `fix_conflict` يقترح max_daily_profit ≥ daily_target بموافقة.
- اختبار كامل بحسابك ثم حذف بيانات التجربة.
